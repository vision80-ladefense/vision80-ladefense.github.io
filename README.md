# vision80-ladefense.github.io

Site d'accès à la résidence Vision 80, Paris La Défense (Courbevoie, 92400).

Publié sur GitHub Pages : https://vision80-ladefense.github.io/

## Pages

1. `index.html` : accueil, les deux adresses, le choix de l'itinéraire, à quoi reconnaître la résidence
2. `metro.html` : arrivée à pied depuis le parvis de la Défense
3. `voiture-paris.html` : voiture depuis Paris, avec la vidéo du trajet
4. `voiture-puteaux.html` : voiture depuis Puteaux, par la voie des Sculpteurs
5. `voiture-nanterre.html` : voiture depuis Nanterre, par le boulevard circulaire

Style commun dans `style.css`, images dans `images/`.

## Origine du contenu

Repris de l'ancien site https://5reflets.wordpress.com/, republié en HTML statique.

L'ordre texte/image du WordPress fait foi : un paragraphe, puis l'image qui l'illustre juste après. Chaque image a été ouverte et vérifiée avant d'être placée, une image mal placée envoyant le visiteur au mauvais endroit.

Site jumeau, centré sur une entrée en particulier : https://5reflets.github.io/ (dépôt `5reflets/5reflets.github.io`). Toute correction sur un itinéraire doit être reportée sur les deux.

## Images

Redimensionnées à 1500 px de large maximum, JPEG qualité 85, chargement différé hors première image. Le site se consulte en mobilité, souvent en 4G : garder le dossier `images/` sous 5 Mo.

Crédits : photo de la résidence par Arthur Weidmann (CC BY-SA 3.0, via Wikipédia), photo du pied de l'immeuble par defense-92.fr, captures d'itinéraire issues de Google Maps et Street View.
